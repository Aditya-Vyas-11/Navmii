AASHII — MAHA NAVAMI WEBSITE

Files:
- index.html : complete responsive website
- aashii.png  : the photo you provided, used in the final reveal

Preview locally:
1. Extract the ZIP.
2. Open index.html in a browser.

Deploy:
- Netlify: drag the extracted folder (containing index.html and aashii.png) into Netlify Drop.
- Vercel: create a project from the folder/repository and deploy as a static site.
- GitHub Pages: upload both files to the same repository root, enable Pages.

Important: Keep aashii.png in the same folder as index.html, otherwise the final photo will not load.
